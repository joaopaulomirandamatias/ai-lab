# Recursos

Material de estudo curado. Quatro listas, cada uma com um papel diferente.

| Arquivo | O que é | Quando abrir |
|---|---|---|
| [`livros.md`](livros.md) | Livros por trilha, com **uma fonte principal ⭐ por tema** | No início de cada mês, para escolher a base |
| [`sites-e-cursos.md`](sites-e-cursos.md) | Cursos, blogs, specs, normas e ferramentas por camada | Ao começar um tema novo, e sempre que precisar da fonte primária |
| [`youtube.md`](youtube.md) | Canais e playlists, com mapa mês a mês | Quando um conceito não entra pelo texto |
| [`papers-essenciais.md`](papers-essenciais.md) | ~70 papers organizados por tema, com ordem de leitura | M16 em diante — e pontualmente antes disso |
| [`projetos.md`](projetos.md) | Os 18 projetos, cada um com **critério de pronto** | Toda vez que um mês começa |

---

## As três regras que fazem essa lista funcionar

**1. Uma fonte principal por tema.**
Três livros de álgebra linear pela metade ensinam menos que um terminado. Os ⭐ marcam
a escolha; o resto é consulta. Isso vale especialmente para YouTube, onde a sensação de
progresso é enganosa.

**2. Uma hora de vídeo, uma hora de implementação.**
Se você não consegue reimplementar o que assistiu, você não assistiu.

**3. Fonte primária sempre que ela existir.**
Para MCP, W3C, OWASP, NIST e EU AI Act não existe tutorial melhor que a especificação.
São documentos normativos, escritos para serem lidos. Ler a spec do MCP em vez do blog
sobre a spec é literalmente a diferença entre o Gate IV e não.

---

## O que essa lista deliberadamente não tem

- **Certificações.** O plano mede progresso por [gate](../00-plano/gates.md), não por
  certificado. Nenhum dos cinco gates é atestado por prova de fornecedor.
- **Cursos pagos caros.** Quase tudo de melhor aqui é gratuito e oficial. O que se paga
  com proveito é GPU, não conteúdo.
- **Tutoriais de framework antes do fundamento.** LangChain e CrewAI aparecem em
  [`sites-e-cursos.md`](sites-e-cursos.md) com a ressalva de usar *depois* de construir
  do zero — porque o Gate IV cobra explicar o mecanismo, e framework é o que impede isso.
