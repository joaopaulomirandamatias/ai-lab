# Checklist operacional da Skill

## Antes
- [ ] Pergunta científica delimitada.
- [ ] Etapa do workflow identificada.
- [ ] Dados classificados.
- [ ] Política institucional/editorial/financiador verificada quando aplicável.
- [ ] Critérios de inclusão/exclusão registrados antes de screening.

## Durante discovery
- [ ] Termos e sinônimos revisados por humano.
- [ ] Base/corpus identificado.
- [ ] Consulta registrada.
- [ ] Resultados tratados como candidatos.

## Durante screening
- [ ] Cada decisão aponta para critério explícito.
- [ ] Ausência de informação resulta em `incerto` quando necessário.
- [ ] Há revisão humana de casos críticos.
- [ ] Falsos negativos potenciais são auditados.

## Durante extração
- [ ] Nenhum campo ausente foi inventado.
- [ ] Trecho/seção de origem foi registrado quando possível.
- [ ] Unidades e definições foram preservadas.

## Durante síntese
- [ ] Corpus é controlado.
- [ ] Conclusões listam estudos de suporte.
- [ ] Divergências não foram apagadas.
- [ ] Associação não foi convertida em causalidade indevidamente.

## Citações
- [ ] Referência existe.
- [ ] Identificador confere.
- [ ] Fonte original foi lida para afirmações críticas.
- [ ] Artigo realmente sustenta a afirmação.
- [ ] Retração/correção foi considerada quando relevante.

## Final
- [ ] AI Research Log preenchido.
- [ ] Limitações documentadas.
- [ ] Decisão humana final identificável.
- [ ] Processo pode ser reconstruído por outra pessoa.
