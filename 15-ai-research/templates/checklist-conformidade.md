# Checklist de Conformidade — IA na Pesquisa

## 1. Tarefa
- [ ] Defini claramente o que a IA fará.
- [ ] Sei por que IA é necessária/útil nesta etapa.
- [ ] Existe alternativa não-IA se houver restrição.

## 2. Dados
- [ ] Classifiquei os dados.
- [ ] Identifiquei dados pessoais.
- [ ] Identifiquei dados sensíveis.
- [ ] Verifiquei confidencialidade.
- [ ] Apliquei minimização.
- [ ] Avaliei anonimização/pseudonimização.
- [ ] Verifiquei política do provedor.

## 3. Governança
- [ ] Consultei política institucional.
- [ ] Consultei protocolo/comitê quando aplicável.
- [ ] Consultei regras do financiador.
- [ ] Consultei regras do periódico.

## 4. Método
- [ ] O procedimento pode ser explicado.
- [ ] Critérios foram definidos antes da automação quando necessário.
- [ ] Há validação humana.
- [ ] Há controle de falsos positivos/negativos.
- [ ] Resultados críticos são conferidos.

## 5. Evidências
- [ ] Referências existem.
- [ ] DOI/metadados foram conferidos.
- [ ] Li a fonte original relevante.
- [ ] A fonte sustenta a afirmação.
- [ ] Não usei IA como fonte primária para fato científico.

## 6. Código e análise
- [ ] Código foi revisado.
- [ ] Existem testes/checagens.
- [ ] Pressupostos estatísticos foram avaliados.
- [ ] Seed registrada quando aplicável.
- [ ] Dependências/versões registradas.

## 7. Transparência
- [ ] AI Research Log preenchido.
- [ ] Uso relevante foi declarado conforme política.
- [ ] Autores humanos assumem responsabilidade pelo resultado.
