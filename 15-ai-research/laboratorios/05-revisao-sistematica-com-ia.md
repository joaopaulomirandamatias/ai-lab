# Laboratório 5 — Revisão Sistemática Assistida por IA
**Duração:** 45–70 min

## Objetivo
Mostrar que IA pode auxiliar partes do workflow sem transformar uma busca informal em revisão sistemática.

## Pipeline

```text
Pergunta
→ protocolo
→ bases
→ strings
→ exportação
→ deduplicação
→ título/resumo
→ texto completo
→ extração
→ risco de viés
→ síntese
→ PRISMA
```

## Experimento
Separe 30–50 títulos/resumos.

1. Defina critérios de inclusão/exclusão antes de usar IA.
2. Faça triagem humana de 10 estudos.
3. Peça à IA para classificar os mesmos 10.
4. Compare discordâncias.
5. Ajuste instruções sem alterar retroativamente os critérios.
6. Classifique os demais.
7. Revise amostra dos excluídos.
8. Documente:
   - modelo/ferramenta;
   - data;
   - prompt;
   - corpus;
   - desempenho observado;
   - intervenção humana.

## Discussão
- Que taxa de erro é aceitável?
- O custo de falso negativo é maior que o de falso positivo?
- A ferramenta deve excluir automaticamente?
- Como relatar isso nos métodos?
