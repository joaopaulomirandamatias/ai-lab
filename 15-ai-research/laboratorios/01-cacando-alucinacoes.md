# Laboratório 1 — Caçando Alucinações Bibliográficas
**Duração:** 25–40 min

## Objetivo
Aprender a auditar referências e separar três problemas:
1. referência inexistente;
2. metadado incorreto;
3. artigo real usado para sustentar afirmação que ele não faz.

## Atividade A — Gere candidatos
Escolha um tema específico e peça a uma IA 8 referências relevantes.

Não peça “as melhores”. Peça:
- título;
- autores;
- ano;
- periódico;
- DOI;
- uma frase sobre a contribuição.

## Atividade B — Verificação
Para cada referência, registre:

| Campo | Resultado |
|---|---|
| Título existe? | |
| Autores conferem? | |
| Ano? | |
| Periódico? | |
| DOI resolve? | |
| Fonte original localizada? | |
| Afirmação da IA aparece no artigo? | |
| Decisão | incluir/excluir/revisar |

Fontes de verificação possíveis:
- Crossref;
- DOI.org;
- PubMed;
- Semantic Scholar;
- OpenAlex;
- site do periódico;
- Google Scholar.

## Atividade C — Evidência
Abra os 3 artigos mais relevantes e localize o trecho que sustenta a afirmação.

## Discussão
- Quantos erros foram encontrados?
- Qual erro seria mais perigoso numa revisão sistemática?
- Uma referência verdadeira pode ser uma “alucinação contextual”?
- Como automatizar parte da auditoria sem confiar cegamente na automação?

## Entregável
`auditoria-referencias.csv` + 1 parágrafo de reflexão.
