# Laboratório 3 — Privacidade, LGPD e Confidencialidade
**Duração:** 25–35 min

Para cada caso, responda:
1. Qual é a classe dos dados?
2. Existe participante humano?
3. Existe confidencialidade contratual ou editorial?
4. Que autorização/política precisa ser verificada?
5. É necessária minimização, anonimização ou pseudonimização?
6. Uma IA pública seria adequada?
7. Que alternativa mais segura existe?

## Casos

### A — Dados abertos do IBGE
Você quer pedir à IA que escreva código de limpeza.

### B — Prontuários identificados
Você quer enviar planilha completa para classificar eventos adversos.

### C — Entrevistas pseudonimizadas
O protocolo menciona análise computacional, mas não uma plataforma externa.

### D — Manuscrito que você está revisando
Você quer enviar o PDF a um chatbot para gerar o parecer.

### E — Dataset empresarial
A empresa permitiu pesquisa acadêmica, mas o contrato proíbe repasse a terceiros.

### F — Artigos open access
Você quer criar um corpus RAG para estudo.
