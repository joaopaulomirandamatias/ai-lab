# Trilha prática — Ferramentas de IA para Pesquisa Científica

Esta trilha complementa a aula principal com uso operacional de **ChatGPT, Claude, Zotero e plugins acadêmicos**, sempre sob o framework **IA-Ciência Auditável**.

> O objetivo não é ensinar a apertar botões. É aprender a transformar uma tarefa científica em um fluxo **rastreável, verificável e reproduzível**.

## Conteúdo

1. [`01-chatgpt-pesquisa.md`](01-chatgpt-pesquisa.md) — pesquisa com ChatGPT, Deep Research, plugins e Skills.
2. [`02-claude-navegador.md`](02-claude-navegador.md) — Claude Research, Claude in Chrome, triagem em bases e segurança.
3. [`03-zotero.md`](03-zotero.md) — captura, organização, citações e integração com IA/Codex.
4. [`04-plugins-academicos.md`](04-plugins-academicos.md) — qual plugin usar em cada etapa.
5. [`05-laboratorio-busca-triagem.md`](05-laboratorio-busca-triagem.md) — laboratório completo de busca, filtragem e matriz de evidências.
6. [`06-laboratorio-skill.md`](06-laboratorio-skill.md) — construir, testar e auditar uma Skill científica.
7. [`07-workflow-end-to-end.md`](07-workflow-end-to-end.md) — do problema ao Zotero e ao AI Research Log.

## Skill pronta

O diretório [`../skills/pesquisa-cientifica-auditavel/`](../skills/pesquisa-cientifica-auditavel/) contém uma Skill reutilizável para descoberta de literatura, triagem, verificação de referências, síntese e auditoria metodológica.

## Carga horária sugerida

| Formato | Atividades | Tempo |
|---|---|---:|
| Demonstração | ChatGPT + Claude + Zotero | 45–60 min |
| Oficina | demonstração + laboratório de busca | 2 h |
| Oficina completa | ferramentas + Skill + workflow end-to-end | 3–4 h |
| Curso estendido | aula principal + toda a trilha prática | 6–8 h |

## Regra operacional

Para toda ação relevante, mantenha a trilha:

```text
Pergunta → ferramenta → fontes/dados → saída → verificação → decisão humana → registro
```
